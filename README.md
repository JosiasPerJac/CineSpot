## Descripción del Proyecto CineSpot

CineSpot es un proyecto académico que se desarrollará en Python y simulará una plataforma de reservas de asientos en una sala de cine.

La situación a resolver consiste en permitir que los usuarios consulten la disponibilidad de los asientos y reserven aquellos que se encuentren libres. El sistema deberá validar cada solicitud y actualizar la disponibilidad al confirmar una reserva, evitando que un mismo asiento sea asignado a más de un usuario para la misma función.

El objetivo es garantizar la correcta asignación de los asientos y mantener un control confiable de su disponibilidad durante el proceso de reserva.
